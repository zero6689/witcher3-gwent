# 背景音乐目录

把《巫师3》原声（例如 **Widow-Maker**）的音频文件放到这个目录里，播放器会自动识别并播放。

## 命名规则

支持以下文件名（任一扩展名 `.mp3` / `.ogg` / `.m4a` / `.wav` 均可）：

| 文件名（不含扩展名） | 曲目 |
|---|---|
| `widow-maker` | Widow-Maker ← **默认第一首** |
| `the-nightingale` | The Nightingale |
| `steel-for-humans` | Steel for Humans |
| `hunt-or-be-hunted` | Hunt or Be Hunted |

例如：`assets/audio/widow-maker.mp3`

## 关于版权

- 这些曲目是 CD Projekt RED / 原作曲者（Marcin Przybyłowicz 等）的**版权作品**，本项目**不随仓库分发**任何音频文件。
- 请使用你**自己拥有**的音频（例如从你购买的游戏安装目录中提取），仅作个人学习娱乐。
- 如果你希望手机端也能听到 BGM，需要把文件一起提交到仓库（GitHub Pages 是公开站点）；
  是否这么做由你自行判断，风险自负。只想本地听的话，放本地不提交即可。
- 没有音频文件时播放器会显示「背景音乐未就绪」，游戏其余功能完全不受影响。
