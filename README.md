# 昆特牌 · 巫师3 网页版（Gwent · TW3）

用 HTML/CSS/原生 JS 复刻的《巫师3：狂猎》内置小游戏**昆特牌**（经典三排版）：
完整核心规则 + 官方卡面 + 卡组编辑器 + 四档难度 + 音效与出牌动画 + 开场动画与结算面板 + 手机端适配。

## 📦 打包成 APK

**正式安装包由本机车道发布**（`scripts\build-apk.ps1`）——只有它能同时保证三件事：

1. **版本号正确**：`scripts/apply-android-version.js` 把根 `package.json` 的版本写进
   `versionCode / versionName`（云端工作流与本地脚本**共用同一个脚本**，不会各写一套）；
2. **能覆盖安装**：用本机固定的 debug 签名密钥，新包可以直接装在旧包上（不用卸载、不丢卡组与战绩）；
3. **资源一致**：内嵌网页资源与线上版本逐字节一致（`node scripts/prepare-www.js` 生成，可逐个核对）。

```powershell
# 1) 下载并安装工具链（JDK 17 + Android SDK 组件，约 700 MB，全部装在项目 .tools/ 内）
powershell -ExecutionPolicy Bypass -File scripts\setup-android.ps1

# 2) 一键编译（prepare-www → cap add android → 写版本号 → 生成图标 → gradle assembleDebug）
powershell -ExecutionPolicy Bypass -File scripts\build-apk.ps1
# 产物：项目根目录 gwent-android-debug.apk
```

发布到 Releases 供直接下载（`<commit>` 用当前的 main）：

```powershell
gh release create v1.1.1 gwent-android-debug.apk --target <commit> --title "..." --notes-file <说明.md>
```

**云端 GitHub Actions 只出构建产物（Artifact），不发布 Release**：打开仓库 **Actions** 页 →
**Build Android APK** → **Run workflow**，跑完在该次运行页面底部下载
**Artifacts → gwent-android-apk**。它的定位是「从源码能不能构建」的自检：runner 的 debug 密钥
**每次都是随机生成的**，那份包**无法覆盖安装**在正式包上（要装得先卸载）。
想改成「云端也发同签名的包」，需把固定 debug 密钥放进仓库 Secret 并在这里还原到
`$HOME/.android/debug.keystore` —— 做法已写在 `.github/workflows/android.yml` 的注释里。

## 功能

### 开场动画与结算
- **开场动画**：首次进入自动播放（狼首徽章 + 金色标题渐显 + 余烬），约 6 秒，可随时「跳过」；主菜单可重播。
- **结算界面**：局末弹出战绩面板 —— 胜负标题、大比分、逐局比分，以及双方对照统计
  （打出单位 / 特殊牌 / 间谍 / 医生复活 / 召唤 / 天气 / 号角 / 焚风 / 领袖技 / 过牌次数 / 出牌总战力）。
- **出牌飞行动画**：手牌点击后从手牌位置带弧线飞到目标排并落位；特殊牌飞向中线消散；AI 出牌从对方信息栏飞出。

### 主菜单与设置
- **主菜单**：开始游戏 / 配置卡牌 / 开场动画 / 音乐与音效 / 关于·声明。
- **设置面板**：背景音乐开关与音量、游戏音效开关、重新开始、返回主菜单。

### 背景音乐（BGM）
- 右下角常驻播放条：上一首 / 播放暂停 / 下一首 / 音量，设置自动记忆。
- 浏览器禁止自动播放 → **首次点击或触摸后自动开始**。
- **内置合成曲**：仓库不附带任何 OST 音频，默认播放一段**原创的中世纪酒馆风循环**
  （Web Audio 实时合成：低音持续音 + 鲁特琴琶音 + 框鼓），无版权问题。
- **换成真正的巫师3 OST**：把文件放进 `assets/audio/`（见该目录 README），
  命名为 `widow-maker.mp3` 等即可自动优先播放，内置合成曲自动让位。

### 卡组编辑器
- 规则与原版一致：**单位牌 22–40 张**、**特殊牌 ≤10 张**、同名卡不超过持有张数；4 位领袖任选其一。
- 卡池支持 **+/− 按钮**与点击加减；底部显示总战力与间谍/医生/召唤/同袍数量统计。
- 「一键填充」按价值优先级自动配好一套合法牌组；牌组按阵营保存在 `localStorage`。

### 难度分级

| 难度 | AI 强度 | 特点 |
|---|---|---|
| 简单 | 0.15 | 牌组更弱（只带 24 张最弱单位）、频繁失误、会无理由过牌 |
| 普通 | 0.5 | 按战力出牌，偶有失误 |
| 困难 | 0.8 | 算牌差、保关键牌、精准过牌、会用领袖技 |
| 大师 | 1.0 | 零失误、完整过牌判断、间谍/医生/召唤连锁、天气压制 |

实测（同一套固定玩家策略，每档 576 局，固定随机种子）：玩家胜率 简单 31% → 普通 19% → 困难 16% → 大师 13%。

### 音效与动画
- **音效全部实时合成**（Web Audio API），零音频文件：出牌、落桌、间谍、医生、召唤、天气、天晴、号角、焚风、诱饵、过牌、局胜/局负、整局胜负。
- 出牌旋转落下、新牌滑入、号角呼吸光晕、焚风与局末全屏闪光、天气特效（结霜/漂雾/斜雨）、总分滚动。

### 规则实现（完整核心规则）

- **三局两胜**；每局双方轮流出牌或「过」，双方都过后比总战力。
- **三排**：近战 / 远程 / 攻城；**天气**使对应排非英雄单位降为 1（**各排独立，互不覆盖**，只有「天晴」清空全部）；
  **号角**使该排非英雄单位 ×2（由玩家点排指定，同一排不叠加）。
- **英雄**免疫天气 / 号角 / 焚风 / 诱饵 / 医生复活。
- **技能**：间谍（抽 2）、医生（从己方坟场复活单位，可连锁）、
  **同袍**（同排每多一张同名卡，每张战力就再乘一倍：n 张 → 每张 ×n、该排合计 ×n²；不同排不互相加成）、
  **召唤**（把同组卡牌全部拉上场：默认**牌堆 + 手牌**一起拉＝真规则，可在「设置」里改成只拉牌堆或整个关掉）、
  鼓舞（同行其它单位 +1，多个鼓舞叠加）、
  **焚风**——分两种口径：特殊牌「焚风」摧毁**全场**最强的一张或多张非英雄单位；单位焚风（**金龙**）在**对方该排总战力 ≥10** 时
  摧毁该排**最强**的非英雄单位（并列全灭）。
- **单卡战力结算顺序**（与参考实现 `asundr/gwent-classic` 的 `Row.calcCardScore` 对齐）：
  同袍倍率 → 鼓舞加算 → 天气（按卡面「降为 1」覆盖）→ 号角/领袖翻倍；
  英雄免疫天气/号角/焚风/诱饵/医生，也不吃鼓舞加成（但英雄的鼓舞**可以**给本排 +1）。
- **领袖技**：每阵营 4 位，每局一次（放晴、整排翻倍、牌组取天气、排焚风、封锁对手领袖等）。
  领袖的「整排翻倍」与号角同效，**不叠加**。怪物「世界毁灭者」（艾瑞汀）弃哪 2 张、
  从牌组取哪 1 张，**都由玩家自己点选**（不再随机/自动）。
- **换牌（开局调度）**：双方各 10 张，**逐张**结算 —— 点一张不要的牌 → 立刻重抽一张（最多 2 次）；
  换掉的牌先放在一边，**本次调度绝不会再抽到**，调度全部结束后才洗回牌堆。AI 也会换牌。
- **小局之间不抽牌**：开局那 10 张用到底。额外摸牌只有：间谍、医生/复活类、领袖技，以及**阵营被动**
  （北方：赢一局抽 1 张；尼弗迦德：平局算赢；松鼠党：**第一局**由该方决定谁先手；怪物：小局结束时随机留 1 张单位在场）。
  小局先手方 = **上一局胜者**；**小局平局 → 双方胜场同时 +1**（所以 1:0 之后打平就是 2:1，整局立刻结束）。
- **出牌交互**：单位点一下落到自己的排；**敏捷/多排单位由你点排决定**（不再自作主张）；
  间谍（多排时）点选放到对方哪一排；天气/天晴/焚风立即生效；**号角由你点排**；只有「诱饵」需要点选目标单位。
- **对手打了什么牌看得见**：底部战斗日志实时留痕 + 对手行动横幅；随时可点「🪦 坟场」查看双方坟场，
  或点「📜 战报」打开**完整对战履历**（对手出牌 / 领袖技 / 焚风摧毁了什么，全部留痕）。

### 2026-09-17 第三轮（v1.0.7：把「同袍 / 召唤」两个技能补完）

- **同袍（Tight Bond）**
  - 口径确认并写死在测试里：**同排 n 张同名 → 每张 ×n，该排合计 ×n²**（3 张 4 战力蓝衣铁卫 = 每张 12、合计 36）。
    依据：`asundr/gwent-classic` 的 `effects.bond[card.id()]` + `total *= bond`。不同排的同名卡不互相加成。
  - 结算顺序改为 **同袍倍率 → 鼓舞加算 → 天气 → 号角**：以前是「先加鼓舞再乘同袍」，导致 3 张同袍带 1 个鼓舞
    算成 (4+1)×3=15；现在是 4×3+1=13（与参考实现一致）。
  - 顺手修掉两个**鼓舞**老问题：① 同一排有 2 个鼓舞单位时，新进场单位只 +1（`break` 早退）→ 现在每个鼓舞各 +1；
    ② 英雄鼓舞单位（伊森格林 / 凯兰）完全不给本排加成 → 现在照常 +1（英雄自身仍然不吃鼓舞）。
- **召唤（Muster）**
  - 口径：**只从牌堆召唤**（卡面原文 "Find any cards with the same name in your deck and play them instantly"）。
    参考实现会连手牌里的同组牌一起拉，本作按卡面取「牌堆」，测试里明确锁住「手上的同组牌不动」。
    ⚠️ **v1.1.0 已改**：玩家实测反馈「游戏里集合会强制打出手牌里的同组牌（血亏）」，所以现在**默认按真规则
    牌堆 + 手牌一起拉**，并给了两个设置开关可以退回本节的「只拉牌堆」或整个关掉（见上一节 #3）。
  - 卡组数据与参考实现逐条核对一致（阿拉哈斯 ×3 + 巨兽、老巫妪 ×3、食尸鬼 ×3、掘地虫 ×3、吸血鬼 ×5、
    矮人/精灵散兵 ×3、哈维卡走私者 ×3），没有缺漏或多算。
  - 医生复活的召唤牌会**再次触发召唤**（与参考实现的 autoplay 一致）。
- **看得见的反馈**
  - 场上同袍牌显示 **×n** 角标（一眼看出「为什么这张是 12 不是 4」）；
  - 手牌上的同袍牌显示「上场后 ×n」、召唤牌显示 **🧲牌堆同组张数**（手机端也有，不依赖悬停提示）；
  - 战斗日志补上「同袍：该排现有 n 张…每张 ×n」与「召唤结算：从牌堆拉出 n 张…」。
- **测试**：`test/rules-test.js` 扩到 **101 例**（同袍 1/2/3 张、跨排、号角、天气、鼓舞顺序与叠加、英雄鼓舞；
  召唤只拉牌堆、手牌不动、空牌堆、医生复活再召唤），`test/ui-smoke.js` 加同袍/召唤角标断言（17 例）。

### 2026-09-17 第二轮（v1.0.6 同版，代码走查后补修）

- 领袖卡面文本与代码行为对齐：两位「摧毁整排」领袖的说明改为「该排**最强**非英雄单位（并列全灭）」。
- 换牌上限改为**整局累计**（多次调用合计也不能超过 2 张）。
- 新一局开始时重算分数：修掉「空场却显示上一局比分」以及留场单位（怪物被动）沿用旧战力缓存的问题。
- 「选择先手」挂起期间禁止出牌/过牌/用领袖技；坟场面板关闭后会恢复未完成的选择弹窗。
- 号角不会再被自动扔到**已被领袖技翻倍**的排（不叠加，等于白扔一张牌），日志也会如实说明。
- 医生复活间谍时清掉「在对方场上」标记（否则无法被诱饵收回，也不再被怪物被动忽略）。
- 医生只能复活本次候选里的**己方**单位（防止越权复活对方坟场的牌）。
- **AI 难度曲线修正**：领袖技使用率改为封顶（原来大师用得比困难还频繁，反而更弱）、
  大师改用「这一手实际会摧毁多少战力」决定排焚风、失误改为真正的降级选择（从评分靠后的一半里挑，
  而不是在全部候选中乱挑——后者会碰巧打出更好的连招，让无失误的大师吃亏）。
  四档曲线恢复单调：简单 27% → 普通 19% → 困难 18% → 大师 17%（玩家胜率，每档 576 局固定种子）。

## 加载性能（v1.0.5 优化）

用真实浏览器（headless Edge + CDP）量过的数据，脚本见 `scripts/perf-audit.js`：

```powershell
node server.js 8099 --host 127.0.0.1      # 另开一个窗口起服务
node scripts/perf-audit.js http://127.0.0.1:8099
# → out/perf-report.json + out/perf-deckbuilder.png + out/perf-board-1080p.png
```

| 项目 | 优化前 | 优化后 |
| --- | --- | --- |
| 单张卡面 | 393×724 / 平均 86 KB | 320×589 / 平均 49 KB（`scripts/fetch-art-small.js 320` 重下） |
| 143 张卡面合计 | 12.1 MB | 6.9 MB |
| 卡池首屏（42 张） | 一次全量解码，逐张冒出 | `<img loading="lazy" decoding="async">`，进入编辑器 0.7s 内全部出图 |
| 重复访问 | 每次重新下载 | Service Worker：卡面 cache-first；脚本/样式 stale-while-revalidate（发布时 `sw.js` 版本号 +1，老玩家下一次打开就拿到新版） |
| 打开网页→主菜单 | 卡面等用户点进去才开始拉 | 空闲时段后台预热（每批 4 张、`fetchPriority: low`、省流/2G 自动跳过） |

另外牌桌尺寸改为**按视口高度自适应**（`--fit-cardw`）：1080p 手牌 68px（比原来的 64px 更大），
768p 自动收到 52px，保证「3+3 排 + 手牌」在 768p～1080p 全都一屏可见、不再把手牌挤到屏幕外。
